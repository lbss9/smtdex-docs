## Gems — Suginami Tunnels

`/battle` → PvE → Exploration → Suginami Tunnels. Open from the start, 5 rooms. Unique drop **18%**.

| Element | Gem | Mitama |
| --- | --- | --- |
| Erthys | Opal | Kusi |
| Aeros | Amethyst | Nigi |
| Aquans | Sapphire | Saki |
| Flaemis | Ruby | Ara |

Any Element also drops **Jade**. Surface is enough. Elements also spawn. Mitamas do **not**.

| Gem | Extra drop | Sell |

| Ruby | Dragon | 400 |

| Opal | — | 400 |
| Sapphire | Snake, Aqua | 400 |

Do not sell gems if you still need Mitamas.

## Mitama paths

1. Fuse two different Elements (`/fuse`).
2. Rag's (`/shop`) — 5,000 / 10,000 / 20,000 or gems.
3. Chamber (`/fuse`) — 100%, +20% on two stats.

## Using items

Heal / revive / status / Magatsuhi: menu and fight. Dampener / Charge / attack stones: **battle only**. Out of battle, heals **do not consume** (the roster does not store HP/MP).
