Mitama is the efficient way to raise STR / MAG / VIT / AGI / LCK. Charge/Concentrate incense **exists**, but it is extremely rare (bosses only) and **not** in the shop.

## Where to farm — Suginami Tunnels

The main farm is **`/battle` → PvE → Exploration → Suginami Tunnels**. Open from the start, 5 rooms. The pool includes all four Elements:

| Element | Color gem | Mitama |
| --- | --- | --- |
| **Erthys** | Opal | Kusi |
| **Aeros** | Amethyst | Nigi |
| **Aquans** | Sapphire | Saki |
| **Flaemis** | Ruby | Ara |

Any Element also drops **Jade**. Unique drop ~**18%**. Surface is enough; Penumbra/Abyss only add more enemies per room. Elements also spawn in the wild. Mitamas **do not**.

## Three paths

1. **Fuse Elements** — Fusion 2 with two different Elements.
2. **Rag's Jewelry** (`/fuse`) — gems or macca (Element 5,000, Mitama 10,000, premium 20,000).
3. **Infusion** — Mitama + recipient, 100% success. The recipient stays.

Selling gems in the shop (250–400 macca) is a bad deal if you still need Mitamas.

## Incense

Strength/Magic Incense grant Charge/Concentrate **in battle**; they do not raise the permanent stat. ~4% drop only from Masakado, Lucifer, Satan, or Beelzebub.
