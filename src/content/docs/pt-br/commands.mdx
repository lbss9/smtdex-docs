---
title: Comandos
description: Todos os comandos slash do SMTDex.
---

Menus só seus incluem **Fechar** e fecham depois de um minuto ocioso, salvo indicação em contrário.

| Comando | Descrição |
| --- | --- |
| `/start` | Escolhe o demon inicial e recebe 500 macca (uma vez). |
| `/battle` | Arena, Exploração, Expedição, Salão Infernal, Duelo ou Confisco. |
| `/party` | Parties de até quatro demons. |
| `/inventory` | Items, demons e Skill Cards. Substitui `/compendium`. |
| `/info` | Catálogo ou um demon seu (stats até 999). |
| `/fuse` | Fusão 2 / 3 / 4, reverso, Mitama e Rag's Jewelry. |
| `/moon` | Fase da lua e chances do spawn. |
| `/mail` | Inbox, enviados, composição. PayIn opcional. **Receber todos** só pega mail grátis. |
| `/shop` | Loja de items por rank de Renome. Vender categoria / tudo. |
| `/balance` | Macca, tamanho da coleção e maior nível. |
| `/profile` | Título de Renome, Ref pública, W/L. |
