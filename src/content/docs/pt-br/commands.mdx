---
title: Comandos
description: Todos os slash commands do SMTDex 2.7.2.
---

Menus só seus incluem **Fechar** e fecham depois de **um minuto** ocioso, salvo o Confisco (90 s).

| Comando | O que faz |
| --- | --- |
| `/start` | Inicial + 500 macca (uma vez). Pixie, Slime, Onmoraki, Cait Sith, Angel. |
| `/battle` | PvE: Arena, Exploração, Expedição, Salão Infernal. PvP: Duelo, Confisco. Manual ou auto. |
| `/party` | Até 4 demons. Criar, editar, apagar. Mitamas fora. |
| `/inventory` | Items (Comum / Valiosos / Talisman / Skill Cards) e demons. Buscar. Aprender. Usar Shard/Crystal. |
| `/info` | Espécie do catálogo **ou** instância sua (IVs, Mitama, moveset). |
| `/fuse` | Fusão 2 / 3 / 4, Reverso, Câmara de Mitamas. Filtro e busca. |
| `/shop` | Comprar items, vender, Rag's (Demons + **Magatsuhi**). Buscar. |
| `/moon` | Fase da lua e odds. `/moon demon:Nome` para uma espécie. |
| `/mail` | Inbox, enviados, compose, PayIn. **Receber todos** só pega mail grátis. |
| `/profile` | Título, Ref, Renome, macca, MAG, W/L, demons X/100. |
| `/balance` | **Mesmo painel** que `/profile`. |

Não existem mais `/compendium`, `/lua`, `/sacrifice` nem `/trade`.
