Macca é a moeda. `/profile` e `/balance` são o mesmo painel: macca, MAG, Renome, W/L, demons **X/100**. Você começa com **500** no `/start`.

Rotas práticas: [onde farmar](../farm/).

## Macca

| Fonte | Fórmula |
| --- | --- |
| Arena / spawn luta / Salão | `Σ nível_inimigo × 7` |
| Exploração | A mesma × **28% / 40% / 55%**; boss ×1,35 |
| Captura por nome | `floor((12 + nv×2 + ★×12) × 0,8)` |
| Chat | **+10** a cada **60 s** |
| Expedição sucesso | 800 / 1 600 / 3 200 / 6 400 / 12 000 |
| Venda | `sell × qty` |

Gasta-se em fusão, Rag's (gemas ou macca) e `/shop`.

## XP

Curva SMT V: XP total para o nível L = `50 × (L − 1)²`. Teto **99**. Uma batalha sobe no máximo **+8** níveis.

Por inimigo, **cada** membro: `nv×8 × 1,15^diff × catchup`, `diff` entre −10 e +10. Catch-up se o inimigo estiver 11+ níveis acima (até ×3,2).

| Fonte | XP |
| --- | --- |
| Arena / spawn / Salão | Fórmula cheia |
| Exploração | Fórmula × 28% / 40% / 55% |
| Chat | **+20** em **todos** os demons / 60 s |
| Expedição sucesso | 2 200–14 000 por demon |
| Duelo / Confisco | **0** |

## Renome

Sobe só, teto **1 000 000**. A loja de items trava o rank 5 em **2 500**. Títulos no `/profile` continuam depois.

| Rank loja | Renome |
| ---: | ---: |
| 1 | 0 |
| 2 | 50 |
| 3 | 200 |
| 4 | 800 |
| 5 | 2 500 |

| Ação | Renome |
| --- | ---: |
| Vitória PvE / Salão | 3 + floor(nv/25) |
| Vitória spawn | 5 + bônus |
| Vitória PvP | 4 + bônus |
| Derrota | 1 |
| Captura | 2 |
| Fusão sucesso / acidente / falha | 6 / 2 / 1 |
| Sala / clear exploração | +1 / +8 / +12 / +18 |

Títulos (exemplos): Errante (0) → Iniciante (15) → Médium (80) → Nahobino (1100) → Magatsuhi (3100) → Ápice (1M).
