`/inventory` substitui `/compendium`. Abre só para você: **Items** | **Demons** | **Fechar**.

## Items

| Aba | O que entra |
| --- | --- |
| Comum | Cura, revive, status, suporte, dampener, ataque, Magatsuhi |
| Valiosos | Loot para vender (junk, gems, barras, Candelabros) |
| Talisman | Selado |
| Skill Cards | Aprender no demon; paginam de 25 em 25 |

**Usar** só em cura / revive / status / Magatsuhi. Charge, dampeners e gems de ataque são **só batalha**.

## Demons

Lista, detalhe, excluir. Teto **100** (mail pendente não conta). Expedição trava exclusão e learn. `/info` mostra stats efetivos (nível, IVs, estrelas, Mitama): atributos até **999**, HP/MP até **9999**.
