Uma party tem até **quatro** demons (`/player` → Grupos). Mínimo 1. Nome até 64 caracteres. **Mitamas não entram em party nem em batalha.** Expedição ativa **trava** a party.

Caps: STR/MAG/VIT/AGI/LCK **por tier** (50 até 5★ · 60 no 6★ · 75 no 7★; bosses ignoram) · HP/MP **9 999** · dano por golpe **99 999** · fases **60** (empate).

## Fórmula de dano (estilo Nocturne)

`base = ((nível + atributo) × poder_da_skill) ÷ 15`

O `atributo` é STR para físico, MAG para mágico. O resultado passa por:

1. **Estágios** de buff/debuff (Kaja / Kunda).
2. **Passivas** (Pleroma, Concentrate/Charge — ×2,5).
3. **Resistência** do alvo (×1,5 fraco · ×0,7 resist · ×0 null · reflete/absorve).
4. **Variação** aleatória entre ×0,95 e ×1,05.

Nenhuma raiz quadrada, nenhum piso complicado — se o número parece alto, é porque `nível + atributo` combinado com a skill deram nisso.

O select de skill mostra a descrição do catálogo e o custo. Magatsuhi só aparece com a barra cheia (`MAG`).

## `/battle`

1. `/battle` (efêmero). Expedição ativa bloqueia.
2. **PvE** ou **PvP**.
3. Quase todo modo pergunta **Controlar party** ou **Batalha automática**.
4. Timeout dos menus: **60 s**. Confisco confirma em **90 s**.

```
/battle
 ├─ PvE
 │   ├─ Arena
 │   ├─ Exploração
 │   ├─ Expedição
 │   └─ Salão Infernal
 └─ PvP
     ├─ Duelo
     └─ Confisco
```

## Press Turn

Cada fase: **1 ícone por aliado vivo**. Ordem: **Agilidade**. Iniciativa: AGI média maior.

| Resultado | Ícones |
| --- | --- |
| Normal / Pass / Guard | Consome **1** |
| Weak ou crítico | ● vira ◐ (turno extra) |
| Miss ou Null | Consome **2** |
| Repel ou Drain | **Zera todos** |
| Magatsuhi | **Não consome**; o mesmo demon age de novo |

Afinidades: Resist ×0,5 · Neutro ×1 · Weak ×1,25 · Severe Weak ×3 · Null 0 · Repel reflete · Drain cura o alvo.

**Guard** reduz dano recebido para **×0,8**. **Passar** gasta 1 ícone. Timeout sem ação = Passar.

Crítico: `5% + (LCK atk − LCK def)×0,4% + (nv atk − nv def)×0,2%`, entre **2% e 85%**. Crítico soma +0,5 no multiplicador.

## Arena

`/battle` → PvE → Arena → party → manual/auto. Party selvagem do **mesmo tamanho**, nivelada e equalizada (piso **85%** da média da party). Lua aplica HP/dano nos inimigos.

**Vitória:** XP (cada membro) + macca (`Σ nv×7`) + drops (42%) + **+3 Renome** (+ `floor(nv/25)`).  
**Derrota / empate 60 fases:** sem loot, **+1 Renome**.

## Exploração / Expedição / Salão

Ver [Exploração](../exploration/), [Expedição](../expedition/), [Salão Infernal](../infernal-hall/). Exploração **não** equaliza — inimigos entram no nível do catálogo. HP/MP resetam entre salas. **Bosses têm MP ilimitado** (skill física ainda cobra HP).

## Duelo

PvP party vs party. Sem aposta, sem transferência. **+4 / +1** Renome. Sem XP/macca PvE.

## Confisco

PvP **1 demon cada** (Mitama fora). Os dois confirmam. O perdedor **perde o demon**. Empate (60 fases): ninguém perde.

## Lua (`/moon`)

`/moon` mostra a fase e as odds. `/moon demon:Nome` a chance da espécie.

| Boost | Janela | HP inimigo | Dano inimigo |
| --- | --- | --- | --- |
| peak | ≤36 h da nova/cheia | ×1,22 | ×1,15 |
| high | ≤72 h | ×1,12 | ×1,08 |
| mild | ≤24 h do quarto | ×1,08 | ×1,04 |
| none | resto | ×1 | ×1 |

Peak/high também empurram 4★/5★/6★/7★ no spawn. Fim de semana (Brasil) dobra as chances dos tiers altos. Lua **não** muda túneis nem o Salão.

## XP e macca de luta

XP por inimigo, **por membro**: `nv×9` × `1,15^diff` (diff −10…+10) × catch-up. Máx. **+8** níveis por batalha. Curva `50×(L−1)²` até 99.

Macca: `Σ nv×6` (exploração aplica 28%/40%/55%). Chat: +10 macca e +20 XP / 60 s.

Rotas: [onde farmar](../farm/). Magatsuhi: [Magatsuhi](../magatsuhi/).
