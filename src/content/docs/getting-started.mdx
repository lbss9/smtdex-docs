## Claim a starter

Use `/start` and pick one of these demons:

- Pixie
- Slime
- Onmoraki
- Cait Sith
- Angel

You receive that demon and **500 macca**. You can only start once.

## What to do next

1. Talk in the server channels. Wild demons spawn about every **three minutes**.
2. When a capture spawn appears, type the demon’s **exact name** to catch it.
3. Open `/compendium` to browse your demons and purchased skills.
4. Build a party with `/party` (up to four demons).
5. Fight with `/battle` — the UI asks whether you want PvE or PvP.

Menus that are only for you (mail, shop, fusion, battle setup, compendium) include a **Fechar** button and close themselves after **one minute** of inactivity.

## Commands you will use often

| Command | What it does |
| --- | --- |
| `/moon` | Current moon phase and spawn odds |
| `/info` | Catalog or owned-demon details |
| `/fuse` | Fusion (2 / 3 / 4 parents, or reverse) |
| `/mail` | Send and receive demons and macca |
| `/shop` | Daily skill shop |
| `/balance` | Macca, collection size, highest level |
