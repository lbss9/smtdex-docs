`/fuse` opens a private UI. Favorites are **not** consumed. Parents list from **highest level** and **omit Mitamas**. Filter (stars, Elements, race) or **Search** by nickname, species, or race.

Fusion stays locked without 2 demons. **Rag's Jewelry** is [`/rags`](../shop/#rags-jewelry--demons).

## Modes

| Mode | Parents | Resolves |
| --- | --- | --- |
| **Fuse 2** | 2 | Race chart **or** 2-parent special **or** Element × Element → Mitama |
| **Fuse 3 / 4** | 3 or 4 | **Special** recipes only (62 total: 7 of 2, 41 of 3, 14 of 4) |
| **Reverse** | — | Pick the result; lists recipes you can afford (up to 40 demons, no Mitamas) |
| **Mitama Chamber** | 1 recipient + Mitamas | Infusion; does **not** create a new species |

Priority: special → Element Mitama → chart dyad.

## Dyad (chart)

Internal target level: `floor((lvA + lvB) / 2) + 1`. The child species is the one in the result race with catalog level ≥ target (or the highest). The child is born at the **species base level**, not the parent average. Fresh IVs **0–31** on every stat.

**37 chart races:** Herald, Megami, Avian, Divine, Yoma, Vile, Raptor, Deity, Wargod, Avatar, Holy, Genma, Fairy, Beast, Jirae, Fiend, Jaki, Wilder, Fury, Lady, Dragon, Kishin, Kunitsu, Femme, Brute, Fallen, Night, Snake, Tyrant, Drake, Haunt, Foul, Enigma, UMA, Qadistu, Devil, Primal.

**Off-chart:** Element, Mitama, King, Panagia. A `-` cell is invalid.

## Element × Element → Mitama

Two **different** Elements. Same Element is invalid. **Dyad** odds (~92%), not 100%.

| Pair | Mitama |
| --- | --- |
| Aeros + Flaemis | Ara Mitama |
| Aquans + Erthys | Ara Mitama |
| Aeros + Erthys | Nigi Mitama |
| Aeros + Aquans | Kusi Mitama |
| Erthys + Flaemis | Kusi Mitama |
| Aquans + Flaemis | Saki Mitama |

## Stars, odds, and macca

Result stars = **minimum of the parents**. Infusion does **not** change species or stars.

Base cost: `15 + result_level × 10`, times the tier multiplier.

| Tier | Targets | Success | Fail | Accident | × cost |
| --- | --- | --- | --- | --- | --- |
| **Dyad** | Chart + Element→Mitama | **92%** | 6% | 2% | ×1 |
| **Special** | Named recipes | **70%** | 25% | 5% | ×4 |
| **Legendary** | Masakado, Lucifer, Satan, Beelzebub, Shiva, Zeus, Michael, Samael | **25%** | 70% | 5% | ×8 |
| **DLC** | Artemis, Cleopatra, Mephisto, Konohana Sakuya, Dagda, Demi-fiend, Demi-fiend A, Nuwa, Nuwa A | **8%** | 90% | 2% | ×15 |
| **Mitama** | Chamber | **100%** | 0% | 0% | ×1 |

Level 50 example: dyad **515** · special **2,060** · legendary **4,120** · DLC **7,725**.

- **Fail:** spends macca, **parents stay**.
- **Accident:** spends macca, **parents vanish**; another demon ±15 levels from the target is born. DLC **never** appears in accidents.

DLC and Mitamas **do not spawn**.

## Inheritance

Pool up to **25** skills (species learnset at the result level + parent movesets). You pick up to **8**.

**Do not inherit** only Infernal Hall **signatures** (rank 99 kit skills) and Gaea Rage / Deadly Fury / Chaotic Will. Racial innates, passives, and Magatsuhi **inherit**. See [Skill Cards](../skill-cards/).

## Mitama Chamber

Mitamas **do not spawn**, **cannot join party/battle**, use **☯** (no stars), and **cannot** be Fuse 2/3/4 or Reverse parents.

**Who can receive:** any demon **except** Mitama and Element.

Each infusion: **+20%** on two stats (floor +1) up to **999**. **HP/MP do not rise**.

| Mitama | Stats |
| --- | --- |
| Ara | STR + AGI |
| Nigi | MAG + LCK |
| Kusi | VIT + AGI |
| Saki | VIT + LCK |

Skills only fill **empty slots** (max 8). At 8 skills, only stats rise. **Quantity** (up to **20**) is set before preview — preview does **not** change quantity. Picking the type lists all five stats: risers show **STR 10 → 16**; the others are just the number. If the stat is already **999**, none enter and all **return**. The line reads **999 cap (won't rise)**.

Paths to a Mitama: fuse Elements, buy at [Rag's](../shop/), farm gems in [Suginami](../farm/).
