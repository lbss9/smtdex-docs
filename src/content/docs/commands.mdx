Private menus include **Close** and time out after **15 idle minutes** ("Sessão expirada"), except Confiscation (90 s).

| Command | What it does |
| --- | --- |
| `/start` | Starter + 500 macca (once). Pixie, Slime, Onmoraki, Cait Sith, Angel. |
| `/battle` | PvE: Arena, Exploration, Expedition, Infernal Hall. PvP: Duel, Confiscation. Manual or auto. |
| `/player` | **Menu-driven inventory + party.** Items, demons, groups. Ephemeral. |
| `/info` | Catalog species **or** your instance (tier, stats, Mitama, moveset). |
| `/fuse` | Fuse 2 / 3 / 4, Reverse, Mitama Chamber. Filter and search. |
| `/rags` | Rag's Jewelry: Elements, Mitamas, **Magatsuhi**. Search. |
| `/shop` | Buy items and sell. Search. |
| `/moon` | Moon phase and odds. `/moon demon:Name` for one species. |
| `/mail` | Inbox, sent, compose, PayIn. **Claim all** only takes free mail. |
| `/profile` | Title, Ref, Renown, macca, MAG, W/L, demons X/100. |
| `/balance` | **The same panel** as `/profile`. |

`/inventory`, `/party`, `/compendium`, `/lua`, `/sacrifice`, and `/trade` no longer exist.

## `/player`

The new home for anything private about your account. Ephemeral response, invoker-only buttons, **15-minute** idle timeout.

```
/player
 ├─ Items 📦
 │   ├─ Consumables 🧪   (heal, revive, status, support, dampener, attack, Magatsuhi)
 │   ├─ Valuables 💎     (gems, key items — candelabra do not sell)
 │   ├─ Talismans 🔮     (sealed for now)
 │   ├─ Skill Cards 🎴   (transferable actives, passives, Magatsuhi)
 │   └─ Back ⬅️ · Close ❌
 ├─ Demons 👥            (list · detail · delete · learn skill)
 ├─ Groups ⚔️            (create · edit · delete parties; up to 4 demons, no Mitamas)
 └─ Close ❌
```

<Aside type="tip">
Learn a skill: **Items → Skill Cards → pick card → pick demon**. The card is consumed. A full moveset (8) asks for a swap.
</Aside>

| `/inventory` demons | `/player → Demons` |

| `/party` list / create / edit / delete | `/player → Groups` |
