---
title: Commands
description: Every SMTDex 2.7.0 slash command.
---

Private menus include **Close** and time out after **one idle minute**, except Confiscation (90 s).

| Command | What it does |
| --- | --- |
| `/start` | Starter + 500 macca (once). Pixie, Slime, Onmoraki, Cait Sith, Angel. |
| `/battle` | PvE: Arena, Exploration, Expedition, Infernal Hall. PvP: Duel, Confiscation. Manual or auto. |
| `/party` | Up to 4 demons. Create, edit, delete. No Mitamas. |
| `/inventory` | Items (Common / Valuables / Talisman / Skill Cards) and demons. Search. Learn. Use Shard/Crystal. |
| `/info` | Catalog species **or** your instance (IVs, Mitama, moveset). |
| `/fuse` | Fuse 2 / 3 / 4, Reverse, Mitama Chamber. Filter and search. |
| `/shop` | Buy items, sell, Rag's (Demons + **Magatsuhi**). Search. |
| `/moon` | Moon phase and odds. `/moon demon:Name` for one species. |
| `/mail` | Inbox, sent, compose, PayIn. **Claim all** only takes free mail. |
| `/profile` | Title, Ref, Renown, macca, MAG, W/L, demons X/100. |
| `/balance` | **The same panel** as `/profile`. |

`/compendium`, `/lua`, `/sacrifice`, and `/trade` no longer exist.
