---
title: Commands
description: Every slash command in SMTDex.
---

Menus that belong to you include **Fechar** and close after one minute idle, unless noted.

| Command | Description |
| --- | --- |
| `/start` | Claim a starter demon and 500 macca (once). |
| `/battle` | Open the battle UI: Arena, Duelo, or Confisco. |
| `/party` | Create and edit parties of up to four demons. |
| `/compendium` | Home with Demons and Skills. No subcommands. |
| `/info` | Catalog or owned-demon details. |
| `/fuse` | Fusion 2 / 3 / 4 and reverse. |
| `/moon` | Moon phase and spawn odds. Optional demon lookup. |
| `/mail` | Inbox, sent mail, compose. Optional `preco` is PayIn. **Receber todos** claims free packages only. |
| `/shop` | Daily skill shop (up to ten offers). |
| `/balance` | Macca, collection size, highest level. |
