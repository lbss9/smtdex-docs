---
title: Commands
description: Every slash command in SMTDex.
---

Private menus include **Fechar** and close after one idle minute unless noted.

| Command | Description |
| --- | --- |
| `/start` | Claim a starter demon and 500 macca (once). |
| `/battle` | Arena, Exploration, Expedition, Infernal Hall, Duelo, or Confisco. |
| `/party` | Parties of up to four demons. Mitamas cannot join. |
| `/inventory` | Items, demons, and Skill Cards. Replaces `/compendium`. **Search** by name. |
| `/info` | Catalog or an owned demon (attributes cap 999, HP/MP 9,999). |
| `/fuse` | Fusion 2 / 3 / 4, reverse, Mitama, and Rag's Jewelry. Filter and search the parent list. |
| `/moon` | Moon phase and spawn odds. |
| `/mail` | Inbox, sent, compose. Optional PayIn. **Receber todos** claims free mail only. |
| `/shop` | Item shop by Renown rank. Sell category / sell all. **Search** by name. |
| `/balance` | Macca, collection size, highest level. |
| `/profile` | Renown title, public Ref, W/L. |
