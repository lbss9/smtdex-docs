# Spawns & Capturing

## How demons appear

As people chat, SMTDex counts messages **per channel**. After a randomized number
of messages, a wild demon spawns in that channel with an embed showing its
**artwork**, category (Race or Arcana), rarity, and which game it comes from.

Each channel has its own counter, so busy channels see demons more often and
quiet channels rarely.

## Capturing

To capture a spawned demon, **type its name** in the same channel:

```
Jack Frost
```

- The **first** person to type the correct name gets it.
- Guessing is not case-sensitive and ignores accents and punctuation.
- Only one demon is active per channel at a time.

## The same demon, many versions

The compendium treats a demon from each game as its **own** entity. The Jack
Frost from *Shin Megami Tensei V* and the one from *Persona 5* are different
catches, with their own level, skillset, and artwork. Capturing one does not
give you the others.

## Rarity

Every demon has a rarity, shown as stars. Rarer demons spawn less often.

| Rarity | Meaning |
| --- | --- |
| ⭐ | Common |
| ⭐⭐ | Uncommon |
| ⭐⭐⭐ | Rare |
| 🌟🌟🌟🌟 | Epic |
| 💠 LENDÁRIO 💠 | Legendary |

## Where demons spawn

By default, demons can appear in any channel the bot can read. Server admins can
restrict spawns to specific channels — see the configuration options in the
**[Command Reference](commands.html)**.
